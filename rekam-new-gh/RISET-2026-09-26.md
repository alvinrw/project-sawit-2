# Riset 2026-09-26 — Banding Frekuensi & Durasi (Pilot Buang)

> **PERINGATAN — hasil frekuensi di dokumen ini dicabut, jangan dipakai.**
> Seluruh angka perbandingan pita di bawah dilakukan **tanpa kalibrasi nada
> ultrasonik**, sehingga tidak ada bukti bahwa rekaman pada 20–28 kHz memang
> terekam pada frekuensi itu dan bukan sesuatu yang lain. Banding antar-pita
> di sini **tidak boleh** dipakai untuk memilih pita analisis, menyaring data,
> atau menyimpulkan apa pun soal frekuensi. Yang masih berguna dari dokumen
> ini hanya bagian durasi (10/15/20 detik) dan catatan procedural.

Catatan internal tim. File di `rekam-new/data/pilot_test/` adalah
file latihan config — DIBUANG dari keputusan, tidak masuk training.

## Setup (dikunci malam ini)

- Board RAK4631 + RAK18032 di COM15 (`239A:8029`), firmware baseline
  (hash `431B2593…`, PCM 62.500 Hz, gain 80) — tidak diubah.
- Mic ngadep bawah deket tanah, tanpa alas/tatakan pot (seragam).
- Tiap tukar isi box: tutup + diamkan 2 menit (aturan wajib — klik start
  dan gema tutup box mengotori ±5 detik pertama, dibuang saat hitung).
- Laptop + kabel tidak disentuh selama rekam.

## Cara banding (ronde selang-seling)

Urutan per ronde: S3→K3→S2→K2→S1→K1 (R10 mulai sawit, R15 mulai kosong,
R20 mulai sawit — biar tren waktu tidak dikira beda sawit).
Durasi: 10, 15, 20 detik. Tiap file dianalisis 4 pita (dBFS):
21–23 | 24–26 | 27–29 | 30–31,25 (kHz). Angka = selisih sawit minus kosong;
plus = sawit lebih kencang.

Kenapa 1 file cukup untuk 4 frekuensi: rekaman 62.500/s memuat semua suara
0–31.250 sekaligus (Nyquist = setengah sample rate). Banding pita = ukur
pakai FFT, bukan kira-kira. Frekuensi diatur di kodingan alat (clock PDM
4 MHz / ratio 64 = 62.500); kodingan yang ada sekarang sudah mencakup
keempat pita — tidak perlu ganti koding untuk banding ini.

## Kesimpulan (jujur)

1. Tidak ada pita yang menang 9/9. Terbaik 27–29 (plus 7/9) tapi besarnya
   loncat 1,6–10,4 dan ronde 20 malah minus 2×.
2. Box kosong goyang sendiri ±2,5 dB tanpa disentuh — beda di bawah itu
   artinya angin lalu.
3. Beda box-vs-pot+tanaman belum tentu suara biologi (gema pot/tanah/
   alas/kabel). Butuh kontrol pot+tanah tanpa tanaman lain waktu.
4. Kodingan yang ada SUDAH CUKUP untuk semua pita ini — jangan ubah
   frekuensi di kode sebelum setup akustik stabil. Default sementara:
   20 detik, tanpa alas, seragam. Status: sementara, bukan kunci.
